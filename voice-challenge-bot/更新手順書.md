# Bot 更新手順書

プロンプト（`data/prompts.json`）や、プログラムのコードを変更したあとに、その変更を動いているBotに反映させるための手順です。

## 1. ターミナルを開く
VSCodeの下部にあるターミナル（コマンドを打ち込む黒い画面）を開きます。
（上部メニューの「ターミナル」＞「新しいターミナル」からでも開けます）

## 1.5 変更したファイルをサーバーに送る

Macでファイルを編集・保存したら、それをOracleサーバーに転送します。
ターミナルで以下のコマンドを実行してください。

【prompts.json だけ変更した場合】
\`\`\`bash
scp -i ~/.ssh/ssh-key-2026-02-24.key /Users/hidehisa/Discord練習会/voice-challenge-bot/data/prompts.json ubuntu@140.238.41.254:~/voice-challenge-bot/data/
\`\`\`

【コード全体を送り直す場合】
\`\`\`bash
scp -i ~/.ssh/ssh-key-2026-02-24.key -r /Users/hidehisa/Discord練習会/voice-challenge-bot/* ubuntu@140.238.41.254:~/voice-challenge-bot/
\`\`\`

### 💡 コマンドの解説
- **scp**: ファイルを安全にコピーして送るコマンドです。
- **-i ~/.ssh/ssh-key-2026-02-24.key**: サーバーの鍵（パスワード代わり）を指定しています。
- **左側**: Mac上のファイルの場所
- **右側**: サーバー上のコピー先

転送が完了したら、サーバーに接続して再起動します。

## 1.7 サーバーに接続する

\`\`\`bash
ssh -i ~/.ssh/ssh-key-2026-02-24.key ubuntu@140.238.41.254
\`\`\`

接続できたら、次の「2. 変更を反映させる（再起動）」に進んでください

## 2：サーバーにファイルを送る
Mac のターミナルを開いて、以下のどちらかを実行。

prompts.json だけ変更した場合（軽い変更）：

scp -i ~/.ssh/ssh-key-2026-02-24.key /Users/hidehisa/Discord練習会/voice-challenge-bot/data/prompts.json ubuntu@140.238.41.254:~/voice-challenge-bot/data/
この場合は Step 3 を飛ばして Step 4 に進んでOK。

コードを変更した場合（全体送り直し）：

scp -i ~/.ssh/ssh-key-2026-02-24.key -r /Users/hidehisa/Discord練習会/voice-challenge-bot/* ubuntu@140.238.41.254:~/voice-challenge-bot/
この場合は必ず Step 3 をやること。

## 3：サーバーで再ビルド（コード全体を送った場合のみ）
サーバーに接続する。

ssh -i ~/.ssh/ssh-key-2026-02-24.key ubuntu@140.238.41.254
接続できたら以下を実行。

cd ~/voice-challenge-bot
npm rebuild better-sqlite3
これを忘れるとBotが起動しなくなる。 Mac 用のファイルが Linux サーバーで動かないため。

## 4：再起動
サーバーに接続した状態で以下を実行。

pm2 restart voice-bot --update-env
表の status が online（緑） になっていれば成功。

## 5：動作確認
Discord で !testpost を送信して、正しく動くか確認する。確認できたらターミナルを閉じてOK。

トラブル時
Botがオフラインになった、反応しない場合。

ssh -i ~/.ssh/ssh-key-2026-02-24.key ubuntu@140.238.41.254
pm2 logs voice-bot --lines 20
ログを見て原因を確認。よくある原因は以下の3つ。

ERR_DLOPEN_FAILED → Step 3 の npm rebuild better-sqlite3 を忘れてる
TokenInvalid → .env のトークンが消えた。nano ~/voice-challenge-bot/.env で確認
JSON の文法エラー → prompts.json のカンマや引用符の閉じ忘れ
ログの確認が終わったら Ctrl+C で戻れる。

### ⚠️ もしうまくいかない（エラーで止まる）場合
ステータスが `errored`（赤色）になってしまったり、DiscordでBotが反応しなくなった場合は、以下のコマンドで「何が原因で止まったのか（ログ）」を確認できます。

```bash
pm2 logs voice-bot
```

これを実行すると、エラーの理由が表示されます。
例えば「プロンプトのJSONファイルを書き換えたときに、うっかりカンマ（`,`）やダブルクォーテーション（`"`）を消してしまった」といった原因がここで分かります。ログの確認が終わったら `Ctrl + C` を押すと元の入力画面に戻れます。
